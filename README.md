# 🔍 진짜 리뷰 필터

유튜브·블로그 리뷰에서 **광고성 멘트를 걸러내고**, 실제 사용자에게 중요한 **치명적 단점 3개 · 핵심 장점 3개**만 카드로 보여주는 AI 앱입니다.
댓글까지 분석해서 **"리뷰어는 괜찮다는데 댓글은 아니라는"** 부분도 찾아냅니다.

## ✨ 핵심 기능
1. 유튜브 영상 링크 / 블로그 링크 / 직접 붙여넣기 입력
2. 스폰서십·광고성 멘트 필터링 + 광고 의심 지수(0~100)
3. 치명적 단점 3개 · 핵심 장점 3개를 **원문 근거 문장과 함께** 카드로 출력
4. 💬 댓글 감지: 광고 의심 댓글 수, 실사용자 의견, 리뷰와 댓글의 차이

## 🚀 실행 방법

### 1. 설치 (Python 3.10 이상)
```bash
git clone <이 저장소 주소>
cd real-review-filter
pip install -r requirements.txt
```

### 2. API 키 넣기
`.env.example` 파일을 복사해서 이름을 `.env` 로 바꾸고 키를 적습니다.
```
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4.1-mini   # 선택 (기본 모델 바꾸기)
YOUTUBE_API_KEY=...   # 선택 (유튜브 댓글 분석용)
```

### 3. 실행
```bash
streamlit run app.py
```
브라우저가 자동으로 열립니다 (안 열리면 http://localhost:8501).

### 4. 프롬프트 비교 실험
```bash
python experiment.py
```
`samples/` 폴더의 리뷰들을 프롬프트 A/B/C로 분석해서 `results/experiment_results.md` 에 저장합니다.

## 🗂️ 파일 구조
| 파일 | 역할 |
|---|---|
| `app.py` | 화면 (Streamlit) |
| `analyzer.py` | OpenAI(GPT) API 호출, 프롬프트 A/B/C |
| `fetchers.py` | 유튜브 자막·댓글, 블로그 본문 가져오기 |
| `experiment.py` | 프롬프트 비교 실험 |
| `samples/` | 실험용 리뷰 (테스트용 가상 데이터) |

## 🛡️ 책임 있는 AI
- API 키는 `.env` 에만 저장하고 GitHub에 올리지 않습니다 (`.gitignore`).
- 이메일·전화번호는 AI에 보내기 전에 자동으로 가립니다. 댓글 작성자 이름은 가져오지 않습니다.
- 분석 결과를 저장하지 않습니다.
- 모든 장단점에 원문 근거를 함께 보여주고, "AI 결과는 틀릴 수 있음"을 화면에 표시합니다.
- 비용 관리: 본문은 15,000자, 댓글은 50개까지만 분석합니다.
