# RealPick AI

> 광고는 걸러내고, 진짜 장단점만 골라보는 AI 리뷰 분석 앱

유튜브·블로그 리뷰에서 **광고성 멘트를 걸러내고**, 실제 사용자에게 중요한 **치명적 단점 3개 · 핵심 장점 3개**만 카드로 보여주는 AI 앱입니다.
댓글까지 분석해서 **"리뷰어는 괜찮다는데 댓글은 아니라는"** 부분도 찾아냅니다.

## ✨ 기능

### 🔎 리뷰 하나 분석
1. **입력**: 유튜브 링크(자막 + 댓글·답글 자동 수집) / 블로그 링크 / 리뷰 글 붙여넣기 — 입력창 하나가 알아서 구분
2. **광고 필터링**: 협찬 고지, 할인·구매 링크, 이벤트 홍보, 근거 없는 과장만 골라 제외 + 광고 의심 지수(0~100)
3. **진짜 장단점**: 치명적 단점 3개 · 핵심 장점 3개를 원문 근거 문장과 함께 표시
4. **▶ 근거 장면 바로가기**: 근거 문장 옆 `▶ 3:42` 를 누르면 유튜버가 그 말을 한 장면부터 재생
5. **🎯 내 사용 목적 맞춤**: "게임용", "출퇴근용", "손이 작은 편" 등을 고르면 나에게 치명적인 단점이 위로
6. **✅ 사기 전에 확인할 것**: 단점을 바탕으로 구매 전 체크리스트 3개
7. **🛡️ 신뢰 점수**: 광고 지수, 광고 지적 댓글 비율, 리뷰와 댓글의 차이, 근거 확인 여부로 **공식 계산** (깎인 이유 표시)
8. **💬 댓글 감지**: 댓글마다 이름표(광고 지적 / 바이럴 / 실사용 경험 / 기타), 개수는 코드가 직접 셈
9. **🙋 리뷰에 물어보기**: "배터리 실제로 몇 시간이래?" — 리뷰와 댓글에 있는 내용으로만 답함
10. **📤 공유 카드**: 결과를 카톡에 보내기 좋은 이미지(PNG)와 복사용 글로 저장

### 📚 여러 리뷰 종합
- 제품 이름만 넣으면 유튜브에서 리뷰를 찾아오거나(YouTube 키 필요), 링크를 최대 5개 붙여넣기
- **"5개 중 4개 리뷰가 말한 단점"** 처럼 공통 단점·장점 순위 (몇 개인지는 코드가 리뷰 번호로 직접 셈)
- 리뷰끼리 평가가 갈린 부분, 리뷰별 신뢰 점수

### ⚖️ 제품 비교
- 제품 A와 B의 리뷰를 각각 종합한 뒤 나란히 비교
- 상황별 추천("통화가 많다면 → A"), 차이점 표, 공통 단점·장점 나란히

### ⚡ 편의
- **같은 영상은 바로**: 한 번 분석한 결과는 `.cache` 폴더에 저장 → 다시 넣으면 기다림 0초, 비용 0원
- **유튜브에서 바로 분석**: 북마크 버튼 또는 크롬 확장 프로그램 (아래 설명)
- **중립성**: 구매 링크·제휴 링크·광고를 넣지 않음

## 🚀 실행 방법 (Windows 기준)

### 1. 설치 (Python 3.10 이상)
```bash
git clone https://github.com/psm333/real-review-filter.git
cd real-review-filter
py -m pip install -r requirements.txt
```

### 2. API 키 넣기
`.env.example` 파일을 복사해서 이름을 `.env` 로 바꾸고 키를 적습니다.
```
OPENAI_API_KEY=sk-...
YOUTUBE_API_KEY=AIza...      # 선택 (유튜브 댓글 분석용, 없으면 자막만 분석)
OPENAI_MODEL=gpt-4.1-mini    # 선택 (기본 모델 바꾸기)
```
- OpenAI 키: platform.openai.com → API keys
- YouTube 키: Google Cloud Console → YouTube Data API v3 사용 설정 → 사용자 인증 정보 → API 키

### 3. 앱 실행
```bash
py -m streamlit run app.py
```
브라우저가 자동으로 열립니다 (안 열리면 http://localhost:8501).
링크가 막히거나 자막이 없는 영상이면 **"직접 붙여넣기"** 로 분석할 수 있습니다.

### 4. 프롬프트 비교 실험 다시 돌리기
```bash
py experiment.py 2
```
`samples/links.txt` 의 유튜브 링크와 `samples/*.txt` 리뷰를 여러 프롬프트·모델로 분석해 `results/experiment_results_2.md` 에 저장합니다.

## 🧩 유튜브에서 버튼 한 번으로 분석하기

**방법 1: 북마크 버튼 (가장 쉬움)**
1. 앱 왼쪽 **🧩 유튜브에서 바로 분석하기** 를 펼쳐 나온 글을 복사
2. 브라우저 북마크바에서 우클릭 → **페이지 추가** → 이름 `RealPick`, **URL** 칸에 붙여넣기
3. 유튜브 리뷰를 보다가 `RealPick` 북마크 클릭 → 새 탭에서 바로 분석

**방법 2: 크롬 확장 프로그램**
1. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 저장소의 `extension` 폴더 선택
3. 툴바의 RealPick 아이콘을 누르면 지금 보는 페이지를 바로 분석
> 앱을 인터넷에 올렸다면 `extension/background.js` 의 `APP_URL` 을 그 주소로 바꾸세요.

## 🌐 인터넷에 올려서 링크로 쓰기 (Streamlit Community Cloud, 무료)
1. [share.streamlit.io](https://share.streamlit.io) 에 GitHub 계정으로 로그인 → **Create app**
2. 저장소 `psm333/real-review-filter`, 파일 `app.py` 선택
3. **Advanced settings → Secrets** 에 키를 적고 **Deploy**
   ```toml
   OPENAI_API_KEY = "sk-..."
   YOUTUBE_API_KEY = "AIza..."
   APP_URL = "https://내-앱-주소.streamlit.app"
   ```
4. 생긴 주소로 폰·다른 컴퓨터에서도 접속 가능
> ⚠️ 클라우드 서버에서는 유튜브가 자막 요청을 막는 경우가 있어요. 그럴 땐 리뷰 글을 붙여넣어 분석하세요.
> ⚠️ 누구나 쓸 수 있게 되므로 OpenAI 사용 한도를 꼭 걸어 두세요.

## 🧪 AI 활용 방식과 실험 결과
유튜브 리뷰 5개 + 가상 리뷰 1개로 프롬프트 4종과 모델 2종을 비교했습니다.

| 프롬프트 | 내용 |
|---|---|
| A | "장단점 3개씩 알려줘" (기준점) |
| B | A + 광고·서론 제외 지시 |
| C | B + 분석가 역할, 광고 판단 기준, 근거 문장 요구, 댓글 분류 |
| **D (최종)** | C에서 **광고의 정의를 좁히고**(의견·단점·사양·가격 언급은 광고 아님) 원문 그대로 복사 강제 |

**2차 실험 결과 (6개 샘플)**

| 조건 | 단점 누락 | 근거 실재율 | 광고문장 실재율 | 평균 시간 |
|---|---|---|---|---|
| A × gpt-4.1-mini | 0/6 | 78% | 100% | 11.1초 |
| B × gpt-4.1-mini | 0/6 | 78% | 88% | 10.0초 |
| C × gpt-4.1-mini | 0/6 | 91% | 86% | 11.6초 |
| **D × gpt-4.1-mini** | **0/6** | **92%** | **96%** | 13.1초 |
| D × gpt-4o-mini | 0/6 | 97% | 100% | 9.9초 |

- 1차 실험에서 C는 리뷰어의 **단점·비판까지 광고로 걸러** 단점이 0개로 나온 사례가 있어 D를 설계했습니다.
- gpt-4o-mini는 자동 채점 수치는 높았지만 단점 누락, 수치 오류(10000mAh → 1000mAh), 근거와 내용 불일치, 추상적인 장점 설명이 있어 **D × gpt-4.1-mini** 를 최종 선택했습니다.
- 자세한 내용: [`results/`](results/)

## ⚠️ 한계와 개선 방향
- 자막이 없는 영상은 분석할 수 없음 → 음성 인식(Whisper 등) 추가
- 가격 정보·비추천 의견을 광고로 오판하는 경우가 일부 남아 있음
- 같은 입력에도 실행마다 결과가 조금씩 달라짐 → temperature 고정, 여러 번 실행 후 합치기
- 자동 채점은 "문장이 원문에 있는지"만 확인하고 "근거가 내용과 맞는지"는 사람이 확인해야 함
- 유튜브 API 특성상 방금 달린 댓글·스팸 처리된 댓글은 수집되지 않음
- 여러 리뷰 종합·제품 비교는 리뷰 5개까지만 사용 (비용·속도) → 리뷰 수가 적으면 결과가 치우칠 수 있음
- 신뢰 점수 공식의 가중치는 직접 정한 값이라 실제 신뢰도와 맞는지 검증이 더 필요함

## 🛡️ 책임 있는 AI
- **API 키**: `.env` 에만 저장하고 GitHub에 올리지 않음 (`.gitignore`), OpenAI 키 만료일 설정, YouTube 키는 YouTube Data API만 쓰도록 제한
- **비용**: OpenAI 사용 한도 $10 강제 설정(초과 시 요청 차단), 본문 15,000자 · 댓글 인기순 50개까지만 분석
- **개인정보**: 이메일·전화번호는 AI에 보내기 전에 자동으로 가림, 댓글 작성자 이름은 수집하지 않음, 분석 결과 저장 안 함
- **AI 결과 표시**: 모든 장단점에 원문 근거를 함께 보여주고, "AI 결과는 틀릴 수 있음"을 화면에 표시
- **테스트 데이터**: 직접 만든 리뷰 샘플은 가상 데이터 사용
